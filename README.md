# NOTSPACE

NOTSPACE is a single-page habit tracker. The Android APK is built and attached to a GitHub release by the **Build Android APK** workflow.

The APK is debug-signed for direct installation (sideloading), not for Google Play. Android may ask users to allow installation from their browser.

Habit data is stored on the device. Google sign-in and sync may not work inside the Android WebView; use the browser version for Google sync.
